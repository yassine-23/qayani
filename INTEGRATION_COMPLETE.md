## 🚀 How to Use (From Any Project)

### Option 1: Direct Agent Invocation

```bash
# From ANY project directory, you can now do:

# Build entire SaaS
Task(
  subagent_type="master-orchestrator",
  prompt="Build a task management SaaS with Kanban boards and AI suggestions"
)

# Generate UI designs
Task(
  subagent_type="design-director",
  prompt="Design a modern dashboard with Apple-inspired aesthetics"
)

# Test existing code
Task(
  subagent_type="qa-agent",
  prompt="Test the dashboard page visually and functionally"
)
```

### Option 2: Shell Aliases (Recommended)

Add to `~/.zshrc` or `~/.bash_profile`:

```bash
# Gemini Agentic System
export GOOGLE_GEMINI_API_KEY="your_key_here"
export NONO_BANANA_PRO_API_KEY="your_key_here"
export GEMINI_AGENTS_PATH="$HOME/Desktop/qayani"

# Quick access aliases
alias gemini-build="python $GEMINI_AGENTS_PATH/agents/orchestrator.py"
alias gemini-design="python $GEMINI_AGENTS_PATH/agents/design_director.py"
alias gemini-test="npx playwright test"
```

Then reload:
```bash
source ~/.zshrc  # or source ~/.bash_profile
```

Now you can use:
```bash
gemini-build --requirements my-app.json
gemini-design --page dashboard
gemini-test --visual-regression
```

### Option 3: Python API

```python
# From any Python script
from gemini_agents import MasterOrchestrator

await orchestrator.build_saas({
    "app_name": "My SaaS",
```

## 🔧 Troubleshooting

### Issue: "Agent not found"
**Solution**: Make sure global CLAUDE.md is loaded
```bash
cat ~/CLAUDE.md | grep "GEMINI 3 PRO AGENTIC"
# Should show the integration section
```

### Issue: API key errors
**Solution**: Set environment variables
```bash
export GOOGLE_GEMINI_API_KEY="your_key_here"
export NONO_BANANA_PRO_API_KEY="your_key_here"
```

### Issue: Rate limits
**Solution**: Agents automatically retry with exponential backoff
```bash
# Or adjust retry settings
export GEMINI_MAX_RETRIES=5
export GEMINI_RETRY_DELAY=10
```

### Issue: Visual tests failing
**Solution**: Adjust similarity threshold
```bash
export VISUAL_SIMILARITY_THRESHOLD=0.90  # Lower from default 0.95
```
