## 🎨 Design Principles Applied (Capture Page)

### **Typography:**
- Font weights: `font-light` (300)
- Sizes: `text-7xl`, `text-8xl` for headlines
- Spacing: `tracking-tight` for headings, `tracking-wide` for body
- Line height: `leading-relaxed`, generous whitespace

### **Colors:**
- **Primary:** `text-gray-900` (near black)
- **Secondary:** `text-gray-600` (medium gray)
- **Tertiary:** `text-gray-500` (light gray)
- **Backgrounds:** `bg-white`, `bg-gray-50`
- **Borders:** `border-gray-200`
- **NO COLORS:** No blue, purple, or gradient accents

### **Spacing:**
- Section margins: `mb-40` (160px between sections)
- Card padding: `p-12`, `p-16`
- Border radius: `rounded-3xl` for soft elegance
- Grid gaps: `gap-16` for breathing room

### **Animation:**
- Duration: `1.2s` (slow, elegant)
- Easing: `ease: [0.25, 0.1, 0.25, 1]` (Apple-style cubic bezier)
- Movement: Subtle `y: 20` offset, gentle opacity fade-ins

### **Components:**
- Dots instead of checkmarks: `w-1.5 h-1.5 bg-gray-900 rounded-full`
- Clean lists with minimal decoration
- Architecture spec sheets with label:content format
- Border separators: `border-t border-gray-200`
